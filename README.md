# Spotify Clone 🎵

## 🌐 Live Demo

[**Click here to try the Spotify Clone**](https://girish-spotify-clone.netlify.app/)

A Spotify-inspired music player built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of a music streaming web player with a dark-themed interface, responsive layouts, dynamically generated song cards, and functional audio playback for the Trending Songs section.

> **Note:** This is an unofficial student project created for educational purposes. It is not affiliated with, endorsed by, or connected to Spotify.

## ✨ Features

- **Spotify-Inspired UI:** Dark-themed interface inspired by Spotify's web player.
- **Trending Songs:** Dynamically generated song cards using JavaScript.
- **Audio Playback:** Play songs directly in the browser.
- **Song Details Page:** View a selected song's cover image, title, artist information, and playback controls.
- **Play/Pause Controls:** Control audio playback with dynamic play/pause icons.
- **Progress Bar:** Track playback progress and seek to a specific position in a song.
- **Song Duration:** Display the current playback time and total duration.
- **Shuffle Songs:** Randomize the order of songs displayed in the Trending Songs section.
- **Scrollable Sections:** Navigate horizontally through song cards using scroll controls.
- **Responsive Design:** Adapt the interface to different screen sizes using CSS media queries.
- **Custom Favicon:** Display a custom favicon in the browser tab.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/girish-slamani-03/Spotify-Clone.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Spotify-Clone
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

4. Select a song in the Trending Songs section to open its player and start listening.

## 📌 Current Limitations

- Functional audio playback is currently implemented for the Trending Songs section.
- Other music sections primarily recreate the interface and may not support full playback functionality.
- The project does not include user authentication, a backend, or Spotify's official music catalogue.
